# Routine Master — Трекер привычек

Проект контейнеризирован с использованием Docker и Docker Compose, а также настроен автоматический CI/CD-пайплайн через GitHub Actions для деплоя на виртуальную машину Yandex Cloud.

---

## Локальный запуск проекта

Для запуска проекта на локальном компьютере вам понадобится только установленный **Docker Desktop**.
Никакие вспомогательные службы (PostgreSQL, Redis) устанавливать отдельно не нужно.

### Шаги для запуска:

1. **Настройка переменных окружения:**
   Создайте в корне проекта файл `.env` и заполнить его по образцу (описан в файле .env.template):
   ```text
   SECRET_KEY=
   DEBUG=True
   ALLOWED_HOSTS=localhost,127.0.0.1,*

   DB_NAME=routine_master_db
   DB_USER=postgres
   DB_PASSWORD=
   DB_HOST=db
   DB_PORT=5432

   REDIS_HOST=redis
   REDIS_PORT=6379
   REDIS_DB=0
   ```

2. **Запуск всей инфраструктуры:**
   Выполните в терминале проекта команду:
   ```bash
   docker compose up -d --build
   ```
   Docker Compose автоматически скачает образы, соберет Django-приложение, запустит базу данных, Redis, воркеры Celery, Celery Beat и веб-сервер Nginx в единой сети.

3. **Применение миграций:**
   После успешного старта контейнеров примените миграции базы данных:
   ```bash
   docker compose run --rm web python manage.py migrate
   ```

Проект станет доступен на локальном компьютере по адресу: [http://localhost/](http://localhost/)

## Настройка CI/CD и деплоя на сервер Яндекса

В репозитории настроен автоматический пайплайн `.github/workflows/action.yml`, который при каждом пуше в ветку проверяет код и обновляет сервер.

### Что делает пайплайн:
1. **Шаг `test`**: Запускает линтер кода `flake8` (проверка PEP 8) и прогоняет встроенные тесты Django в изолированной базе данных SQLite.
2. **Шаг `build`**: Собирает стабильный Docker-образ проекта и отправляет его в реестр Docker Hub.
3. **Шаг `deploy`**: Подключается к удаленному серверу Yandex Cloud по SSH, генерирует из секретов свежие файлы `.env` и `nginx.conf`, копирует `docker-compose.yml` и перезапускает систему через Docker Compose, автоматически выполняя новые миграции.

### Обязательные секреты (GitHub Secrets):
Для работы деплоя в настройках репозитория (**Settings -> Secrets and variables -> Actions**) добавлены следующие ключи:
* `SSH_KEY` — Приватный SSH-ключ для доступа к виртуальной машине Яндекса.
* `SSH_HOST` — Публичный IP-адрес виртуальной машины.
* `SSH_USER` — Имя пользователя сервера (`ubuntu`).
* `DOCKER_USERNAME` и `DOCKER_PASSWORD` — Учетные данные от аккаунта Docker Hub.
* `NGINX_CONF` — Текст конфигурационного файла `nginx.conf`.
* `ENV_FILE` — Содержимое файла `.env` с флагом `DEBUG=False` и актуальным IP-адресом в `ALLOWED_HOSTS`.
